# 【优质服务】市妇幼保健院开设复发性流产、保胎专病门诊

> 更新时间：2026-09-16 (UTC+8)

****
**复发性流产、保胎专病的优质服务**

市妇幼保健院

开设复发性流产、保胎专病门诊

在确认妊娠的女性中，合并流产风险为15.35%，越来越多的女性出现反复流产，为提升本市生殖健康技术水平，马鞍山市妇幼保健院生殖医学中心正式开设“复发性流产、保胎专病门诊”。

每周一下午由“江淮名医”、马鞍山市妇幼保健院副院长、生殖医学中心总负责人潘维君主任亲自坐诊。同时大力推进驿马工程，引进“全国知名专家”、上海市第一妇婴保健院生殖免疫科主任鲍时华博士，每月一次线上诊疗。

2022年5月27日，鲍时华博士首次在市妇幼生殖医学中心开设线上门诊，就诊资料由生殖中心医生提前整理好，并向鲍时华博士汇报、沟通，当日共接诊10名反复妊娠失败患者，鲍博士线上解答患者夫妇对孕育的疑惑，并结合每对夫妇的具体情况，给出个体化的诊疗方案。

马鞍山市妇幼保健院肩负着全市妇女的生殖健康，此次“复发性流产、保胎专病门诊”的开设，是医务人员职责的需要，也是医院妇产科学科发展的需要。保胎专病门诊的建设填补了马鞍山市该领域的空白，将为全市复发性流产、不良妊娠史的女性提供全面的病因筛查、个性化的保胎，足不出户在“家门口”就可以享受长三角高质量的医疗保健服务，让她们早日怀上孕、抱上娃。

❖ 

**复发性流产、保胎专病门诊诊疗范围**

1. 妊娠后流产（胎停）次数≥2次（包括空孕囊、无胎心、胎心消失等）；

2. 生化妊娠次数≥2次；

3. 试管胚胎移植失败（不着床次数≥2次）；

4. 只有一次胎停史，但心理非常紧张者；

5. 既往有妊娠3个月后自然流产、不明原因胎死宫内、胎儿宫内生长受限、28周前胎膜早破及早产、不明原因羊水过少、宫颈机能不全等；

6. 抗磷脂综合征、自身免疫病、不明原因等引起的不孕及流产；

7. 不良妊娠史孕期保胎与咨询指导。
